# Weather translations

The `en` document and manifest are exported from the current source by Libertas
Studio. The `zh-Hans` document preserves existing translations by declaration
identity and translates the 14 Nullable answer captions added in October 2026.
Other newly added text remains in English; this is a partial locale update.

`TRANSLATION-WORKSET.json`, `TRANSLATION-RESULT.json`, and
`CODEX_TRANSLATION.md` record this bounded caption update. No trusted automatic
translation baseline is recorded for the partial locale.

Use the [Studio translation workflow](https://github.com/LibertasIoT/libertas-doc/blob/main/guides/translation.md)
to refresh or extend the translation.
